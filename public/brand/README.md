# SpikeDate logo assets

The app icon uses the selected solid Vermilion `#FF4B32` heart and spike on Midnight `#0B0C12`. In the mobile header the symbol sits beside a compact `SpikeDate` wordmark.

- `spikedate-icon.svg` — solid Vermilion app icon master
- `spikedate-symbol-gradient.svg` — gradient symbol on transparency
- `spikedate-symbol-vermilion.svg` — current solid Vermilion mark on transparency, shared by in-app and static lockups
- `spikedate-symbol-white.svg` / `spikedate-symbol-navy.svg` — one-color symbols
- `spikedate-logo-horizontal.svg` / `spikedate-logo-vertical.svg` — full-color lockups
- `spikedate-logo-*-white.svg` / `spikedate-logo-*-navy.svg` — one-color lockups
- `app-icon-24.png`, `app-icon-48.png`, `app-icon-192.png`, `app-icon-512.png`, `app-icon-1024.png` — web and store-ready PNG exports
- `icon-options/` — selected Vermilion comparison, alternate color previews, and the previous gradient source
- `spikedate-splash.svg` — launch-screen master
- `spikedate-splash-2732.png` — high-resolution launch-screen export

Selected icon colors: Midnight `#0B0C12` and Vermilion `#FF4B32`.
